Right now that means computer vision and forecasting models in production, event-driven pipelines on AWS, and the Terraform underneath them. Before that I spent a summer at AMD benchmarking mixed-precision iterative refinement in C++ against the AOCL-DA libraries, which is where the interest in numerics started.
